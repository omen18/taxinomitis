# Security Policy

## Supported Versions

Critical security updates are applied to the latest version of the application.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Machine Learning for Kids (taxinomitis) seriously. If you believe you have found a security vulnerability in this project, please report it responsibly:

1. **Do NOT open a public GitHub issue** to report a suspected vulnerability.
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the project maintainers.
3. Please include:
   - A detailed description of the vulnerability
   - Clear steps to reproduce the issue (proof-of-concept script or curl commands if applicable)
   - The potential impact of the vulnerability

We appreciate your efforts to responsibly disclose your findings and will make every effort to acknowledge and address confirmed vulnerabilities promptly.
